# CIRCULUS Agent Rules

1. Read the existing code before modifying it.
2. Prefer minimal diffs.
3. Never rewrite working code unnecessarily.
4. Never expose secrets.
5. Never hardcode API keys.
6. Never fabricate blockchain transactions.
7. Never label mock blockchain data as on-chain.
8. Never generate fake testimonials or fake customer data presented as real.
9. Never invent scientific measurements.
10. Clearly label prototype estimates.
11. Reuse existing components.
12. Keep UI components composable but simple.
13. Use Motion only where it improves understanding or delight.
14. Respect reduced motion.
15. Run typecheck/lint/tests after meaningful changes.
16. Do not modify unrelated files.
17. Do not create fake commit history.
18. Do not add libraries without justification.
19. Prefer server-side API calls for secrets.
20. Keep the repository runnable from a fresh clone.
21. Inspect existing features before rebuilding.
22. Add India-specific fields progressively.
23. Do not claim legal, regulatory, scientific, carbon-credit or on-chain verification without evidence.
24. Use mock data only when labelled.
25. Keep Gemini and Polygon optional at runtime.
26. Provide graceful fallbacks.
